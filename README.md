# Kalavidara Balaga

Kalavidara Balaga is an Android application designed to connect artists, promote cultural activities, and manage community events through a simple and user-friendly interface.

## Features

- User Registration & Login
- Artist Profile Management
- Event Listings
- Cultural Program Updates
- Firebase Integration
- Responsive Android UI
- Secure Data Storage

## Tech Stack

- Android Studio
- Kotlin
- XML Layouts
- Firebase Authentication
- Firebase Realtime Database / Firestore
- Material Design Components

## Installation

### Clone Repository

```bash
git clone https://github.com/spunith0101-cell/Kalavidara-Balaga.git
```

### Open Project

1. Open Android Studio
2. Select **Open Existing Project**
3. Choose the cloned folder
4. Sync Gradle
5. Run on Emulator or Android Device

## Project Structure

```
app/
├── activities/
├── adapters/
├── models/
├── firebase/
├── layouts/
└── resources/
```

## Requirements

- Android Studio Hedgehog or later
- Android SDK 24+
- Internet Connection
- Firebase Project Configuration

## Firebase Setup

1. Create a Firebase Project
2. Add Android App
3. Download `google-services.json`
4. Place it inside:

```
app/google-services.json
```

5. Sync Gradle and run the project
